# 欢迎来到我的技术博客 👋

这是我的个人技术博客，用于积累和分享技术文章。

## 功能特性

- 📝 **Markdown 写作** — 支持完整的 Markdown 语法和代码高亮
- 📦 **文章归档** — 按年月自动归档
- 🏷️ **分类与标签** — 多维度组织文章
- 💬 **评论系统** — 基于 GitHub Discussions
- 🔐 **管理后台** — 在线编辑、上传、删除文章
- 📥 **模板下载** — 快速开始新文章
- 👤 **个人资料** — 在线编辑个人信息
- 📱 **响应式设计** — 完美适配移动端
- 🌙 **暗色模式** — 自动跟随系统主题

## 如何使用

### 浏览文章
在首页点击任意文章卡片即可阅读全文。

### 管理文章
1. 点击右上角「登录」
2. 输入账号和密码
3. 在管理面板中可以新建、编辑、删除文章

### 评论
文章底部支持评论，需要登录 GitHub 账号。
